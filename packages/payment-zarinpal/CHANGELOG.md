### Added

- Zarinpal GraphQL gateway adapter (`ZarinpalGateway`) based on `zarinpall.md` specification.
- GraphQL request payment, startpay redirect, verify payment, and callback parsing.
- Error mapper for Zarinpal GraphQL error structures.
