# Changelog - @company/payment-zibal

All notable changes to `@company/payment-zibal` will be documented in this file.

## [1.0.0] - initial release

### Added
- Zibal IPG provider gateway adapter (`ZibalGateway`) based on `ziball.json` specification.
- Payment request, redirect URL generation, verification, inquiry, and callback parsing.
- Zibal error code mapper and sandbox test suite integration.
