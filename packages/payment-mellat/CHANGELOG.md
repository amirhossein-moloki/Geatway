# Changelog - @amirhossein-moloki/payment-mellat

All notable changes to `@amirhossein-moloki/payment-mellat` will be documented in this file.

## [1.0.0] - initial release

### Added

- Mellat PSP gateway adapter (`MellatGateway`) implementing `Mellat.md` specification.
- Payment token request, verify, refund, reverse, inquiry, and callback parsing capabilities.
- Mellat error response mapper and status code translation.
