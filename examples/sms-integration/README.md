# SMS Integration Example

Reference application demonstrating how to wire `@amirhossein-moloki/sms-core`, `@amirhossein-moloki/sms-melipayamak`, and `@amirhossein-moloki/sms-smsir` into a TypeScript application backend.

## Contents

- `src/index.ts` — Express-compatible application controller and service setup
- `tests/sms-integration.test.ts` — Vitest unit and integration test suite using mock SMS provider
- `openapi.yml` — OpenAPI specification contract for SMS REST endpoints
